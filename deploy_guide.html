部署指南 免费方案

使用 Cloudflare Worker + Pages，将访谈应用发布为公网链接，对外分发无需任何服务器。

部署架构

用户浏览器 → 访问 interview.pages.dev（Cloudflare Pages 托管 HTML） → 调用 proxy.workers.dev（Cloudflare Worker，携带 API Key） → 转发到 DeepSeek API

API Key 只存在 Worker 的环境变量中，前端源码里看不到，可以安全分发链接。
1
注册 Cloudflare 账号
已有账号可跳过
  1. 访问 dash.cloudflare.com，点击 Sign Up
  2. 填写邮箱和密码完成注册，不需要绑卡、不需要域名
  3. 验证邮箱后登录控制台
免费套餐每天有 100,000 次 Worker 请求额度，日均几十次访谈完全够用。
2
创建并部署 Worker（API 代理）
把 API Key 存在服务端
  1. 在控制台左侧菜单点 Workers & Pages → Create
  2. 选 Create Worker，名称填 interview-proxy，点 Deploy
  3. 部署成功后点 Edit Code，删除默认内容，把 worker.js 文件中的全部内容粘贴进去，点右上角 Deploy

配置环境变量（存 API Key）：

  1. 回到 Worker 详情页，点 Settings → Variables and Secrets
  2. 点 Add variable，名称填 DEEPSEEK_API_KEY，值填你的 DeepSeek Key（sk-xxx），类型选 Secret
  3. 点 Save and deploy

此时 Worker 地址类似：

https://interview-proxy.你的用户名.workers.dev
先复制这个地址，下一步要填进 HTML 文件里。
3
修改 interview_app.html，填入 Worker 地址
让前端知道去哪里发请求

用文本编辑器（记事本或 VS Code）打开 interview_app.html，找到文件顶部 JS 的这一行：

const PROXY_URL = '';

改为你的 Worker 地址：

const PROXY_URL = 'https://interview-proxy.你的用户名.workers.dev';

保存文件。

填入 PROXY_URL 后，页面上的「API Key 输入框」会自动隐藏，用户打开链接直接填被访谈人信息就能用。
4
上传 HTML 到 Cloudflare Pages
生成公网链接
  1. 在控制台 Workers & Pages → Create → 选 Pages → Upload assets
  2. 项目名称填 interview-app（或任意名称），点 Create project
  3. 把修改好的 interview_app.html 重命名为 index.html，然后拖入上传区域
  4. 点 Deploy site，等几秒完成

部署成功后，你会得到一个类似这样的链接：

https://interview-app.pages.dev

把这个链接发给同事，打开即用，无需安装任何东西。

以后更新 HTML 内容：回到 Pages 项目 → Deployments → 上传新文件即可，链接不变。
5
解决跨域问题（如遇到）
通常不需要，仅在请求被拦截时操作

Worker 代码已内置 CORS 允许所有来源（*）。如果你希望只允许自己的 Pages 域名访问，在 Worker 环境变量中额外添加：

ALLOWED_ORIGIN = https://interview-app.pages.dev

不配置则默认允许任何域名（对内部工具来说没有安全问题）。

完成后的使用流程

同事收到链接 → 浏览器打开 → 填写被访谈人姓名、岗位、访谈主题 → 点「开始访谈」→ AI 全程主导对话 → 点「生成报告」→ 复制结构化报告粘贴归档。
