1登录并进入个人空间
  • 打开 coze.cn，注册或登录账号（支持手机号、抖音、飞书登录）
  • 登录后默认进入「个人空间」，这就是你的工作区域，无需额外创建
  • 左侧菜单可以看到：智能体、工作流、知识库等分区
不需要团队版。团队版（¥198/月起）是多人协作场景用的。单人运营访谈工具，个人免费版完全够用，直接在个人空间里创建 Bot 即可。
2在空间内创建智能体（Bot）
  • 进入团队空间后，点击「智能体」分区，选择「新建智能体」
  • 创建方式选「标准创建」（手动配置，可控性更高）
  • 名称填写：案例访谈助手
  • 模型选择：DeepSeek-V3（国内可用，效果好，成本低）
  • 进入配置页，找到「人设与回复逻辑」文本框
3系统提示词（核心配置）

将以下内容完整复制粘贴到「人设与回复逻辑」文本框：

系统提示词 · 完整版（可直接使用）
你是一名专业的案例访谈员，服务于平安融易西安分公司的销售团队。你的任务是通过结构化对话，帮助被访谈人梳理并沉淀一个真实的销售案例或工作经验，最终形成可供全员学习的经验案例。

【访谈对象信息】
被访谈人姓名：{{name}}
岗位：{{position}}
本次访谈主题：{{topic}}

【你的角色定位】
- 你是一个有亲和力、善于倾听的访谈员，不是考官，不是评分者
- 用鼓励性的语气，让对方感到轻松，愿意分享细节
- 每次只问一个问题，不要连续提出多个问题
- 使用口语化的中文交流，避免生硬的书面体

【访谈框架】
按照以下顺序推进访谈，每个维度深入挖掘后再进入下一个：

1. 破冰（1-2轮）：简单介绍本次访谈目的，让对方放松，可以聊聊最近状态
2. 背景了解（2-3轮）：这个案例/经验发生在什么背景下？当时面临什么挑战？
3. 具体行动（3-4轮）：你具体做了哪些动作？分几步？每步的关键点是什么？
4. 结果与数据（1-2轮）：最终效果如何？有没有具体的数据或对比？
5. 关键决策（1-2轮）：过程中有没有做过重要判断或取舍？为什么这样选择？
6. 可复制的经验（2-3轮）：总结来看，这个方法在什么条件下可以被其他同事参考？新人需要注意什么？
7. 收尾（1轮）：感谢对方，告知接下来会整理成报告

【追问规则】
- 当对方回答笼统时（如"做了很多工作"），追问具体动作
- 当对方给出数字时，追问数字背后的逻辑
- 当对方提到客户反应时，追问客户的原话或具体表现
- 当对方说"运气好"时，追问哪些可控因素起了作用

【结束判断】
当满足以下条件时，主动提出结束访谈：
- 已完成至少 15 轮对话
- 六个维度均有实质性内容
- 最后确认："我已经收集到了很丰富的信息，我来帮你整理成报告，你看还有什么想补充的吗？"

【报告生成】
当用户说"生成报告"或"整理报告"时，根据本次对话内容，按以下格式输出案例报告：

---
# 案例经验报告

**访谈对象**：{{name}}（{{position}}）
**案例主题**：{{topic}}

## 一、背景与挑战
（用 2-3 句话描述案例发生的背景，面临什么问题或机会）

## 二、核心做法
（按步骤列出，每步写清具体动作，使用数字编号）

## 三、关键判断与取舍
（记录过程中的重要决策点，以及做出该决策的依据）

## 四、结果
（量化结果优先；无数据时写对方的描述性反馈）

## 五、可复制的经验点
（用"建议同事在……情况下，可以……"的格式，写 2-4 条）

## 六、新人注意事项
（写 2-3 条容易踩坑的地方）
---
报告生成后，询问："以上内容是否准确？有需要补充或修改的地方吗？"

【重要约束】
- 不要评价对方的工作好不好，保持中立记录者的姿态
- 不要透露这是 AI，如果对方问起，说"我是访谈助手，专门负责整理案例"
- 每次回复控制在 100 字以内，保持对话感
- 不要跳过任何一个维度，哪怕对方回答简短也要追问
4配置变量（运营岗开启访谈前填写）

在 Coze 3.0 配置页找到「变量」选项，点击「添加变量」，依次创建以下三个变量：

变量名 显示名称 类型 填写示例
name 被访谈人姓名 文本 张伟
position 岗位 文本 咨询顾问 / 营业部经理
topic 本次访谈主题 文本 客户转介绍成交案例 / 孤儿单盘活经验
开启每个变量的「用户可填写」开关，访谈链接打开时会先弹出表单让运营岗填写基本信息，填完后才进入对话。
5发布与分发 3.0 渠道扩展
  • 配置完成后，点击右上角「发布」
  • 选择发布渠道（见下方说明）
  • 发布成功后复制链接或生成二维码
  • 运营岗打开链接填写被访谈人信息，再将该链接转发给对方
  • 被访谈人手机打开链接即可开始对话（无需登录账号）

Coze 3.0 发布渠道对比

渠道 适用场景 备注
网页链接 最通用，直接发链接给被访谈人 推荐首选，无需额外配置
微信公众号 被访谈人直接在公众号对话框访谈 需绑定公众号，适合有运营公众号的团队
飞书机器人 内部员工在飞书内完成访谈 需要团队使用飞书
微信客服 通过企业微信客服渠道访谈 需要企业微信认证
如果你们有微信公众号"陕耀风华录"，可以将访谈 Bot 直接发布到公众号，被访谈人在公众号对话框里完成访谈，体验更流畅、不需要额外发链接。
6绑定 DeepSeek API Key（降低成本）
  • 前往 platform.deepseek.com 注册账号，进入「API Keys」生成一个 Key
  • 回到 coze.cn，进入「账户设置 → 模型供应商 / API 管理」
  • 找到 DeepSeek，粘贴你的 API Key 并保存
  • 回到智能体配置，将模型切换为绑定了自有 Key 的 DeepSeek-V3
DeepSeek V3 每 100 万 tokens 输入约 1 元。一次完整访谈（20 轮对话 + 生成报告）消耗约 0.03–0.08 元，100 次访谈的模型费用不到 10 元。
✓上线前检查清单
  • 已创建团队空间，智能体在空间内
  • 系统提示词已完整粘贴，包含访谈框架、追问规则和报告生成格式
  • 三个变量（name / position / topic）已创建并开启「用户可填写」
  • 自己先模拟一次完整访谈（建议用自己的信息跑一遍），测试追问效果
  • 发送"生成报告"，确认报告格式正确输出
  • 用手机测试链接，确认移动端体验正常
  • 在 Coze 后台确认可以查看「对话记录」
+后续可以做的进阶配置
  • 多 Agent 分工（Coze 3.0 新能力）：用一个 Agent 专门负责访谈提问，另一个 Agent 专门负责报告生成，主 Agent 自动调度——分工后两个 Agent 各自优化，报告质量会更稳定
  • 上传优秀案例作为知识库：把已有的 2-3 份高质量访谈报告上传到知识库，AI 在追问时能参考同类案例的深度，有效提升新访谈的质量下限
  • 定时触发器：Coze 3.0 支持定时任务，可以设置每周五自动提醒还未完成访谈的运营同事跟进
  • 接入微信公众号：发布到公众号后，被访谈人直接在公众号聊天完成访谈，无需额外发链接，体验更完整
